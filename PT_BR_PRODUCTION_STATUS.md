# Brazilian Portuguese Production Status

This tracker covers the Brazilian Portuguese (`pt-BR`) production batch for the AI Security Manuals repository.

## Completion standard

A manual is complete only after all of the following are finished:

- Brazilian Portuguese DOCX created from the English source master
- Brazilian Portuguese PDF exported from the verified DOCX
- Technical terminology reviewed for Brazilian Portuguese
- DOCX opens without repair warnings
- DOCX rendered and every page visually inspected
- PDF rendered and every page visually inspected
- PDF text confirmed searchable and selectable
- Headings, tables, lists, links, page breaks, headers, footers, and reading order checked
- No placeholder text, copied metadata, missing glyphs, clipping, or overlap
- Root README catalog updated
- Topic/platform README updated where applicable
- CHANGELOG.md updated
- Version and status records updated

## Editorial note

Machine-assisted translation may support drafting, but publication requires terminology, meaning, formatting, accessibility, and visual checks. A file or link must not be marked complete before those checks are documented.
